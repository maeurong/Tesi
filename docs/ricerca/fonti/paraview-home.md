## Using ParaView on the Web and In Situ

Our award-winning software allows you to analyze and visualize data in any setting, from supercomputers to analyze exascale datasets to laptops for smaller-sized data. It can also be run in situ using [ParaView Catalyst](https://www.paraview.org/insitu/) and in a web browser using [trame](https://kitware.github.io/trame/index.html). Ensure you’re effectively leveraging ParaView by taking advantage of these features.
